Claude (AI ideas)

Tunesmith uses your own Claude API key. It is stored encrypted on this computer and only sent to Anthropic. Usage is billed to your Anthropic account.

Get a key at console.anthropic.com → API keys.

Keyboard shortcuts

  • AWSEDFTGYHUJK play notes (like a piano)
  • Z / X octave down / up · Space play / stop
  • Backspace remove the last (or selected) note · Ctrl/⌘Z undo
  • A USB/MIDI keyboard works too: just plug it in.
